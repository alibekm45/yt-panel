YT панель

Личная локальная панель владельца YouTube-каналов. Она запускается только на компьютере владельца и показывает статистику его собственных каналов (просмотры, время просмотра, подписчики) через YouTube Data API и YouTube Analytics API.

Приложение не публичное и не предназначено для других пользователей.
