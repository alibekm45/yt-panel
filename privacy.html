Политика конфиденциальности

«YT панель» — личный инструмент, который работает только на компьютере владельца каналов.

  • Приложение запрашивает доступ только на чтение к YouTube-каналам владельца (youtube.readonly, yt-analytics.readonly).
  • Полученные ключи доступа и статистика хранятся только локально на компьютере владельца и никуда не передаются.
  • Данные не продаются, не передаются третьим лицам и не используются для рекламы.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных Google API соответствует Google API Services User Data Policy.
